# Knight Run Workshop Images

Images for the Steam Workshop pages of the Knight Run RimWorld mod series, a non-commercial fan mod of the webtoon 「나이트런」 (Knight Run).
Knight Run is the work of its original authors. These images are the mod's own art and in-game screenshots.

- `kaiju/banners/`: one banner per kind of content (Knight Run - Kaiju)
- `kaiju/photos/`: in-game screenshots, 960x540
